# LearnHub frontend

The frontend is built with React, Vite, React Router, and Tailwind CSS 4.

## Run locally

```powershell
npm install
npm run dev
```

The Vite development server runs on `http://localhost:5173` and proxies `/api` requests to the backend at `http://localhost:5000`. Start the backend and MongoDB as described in the [project README](../README.md).

## Checks

```powershell
npm run build
npm run lint
```
